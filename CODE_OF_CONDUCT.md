# Code of conduct

FotoTag adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) ([Italian translation](https://www.contributor-covenant.org/it/version/2/1/code_of_conduct/)).

In short: be respectful, criticize ideas rather than people, and don't harass anyone.

## Reporting

To report unacceptable behavior, contact the maintainer privately through their GitHub profile, [@f-loren](https://github.com/f-loren). Reports are kept confidential.
